How to refresh this page
Automatically (data)
The GitHub Actions workflow Crypto Bot runs hourly at minute :30 UTC, commits the new state, and rebuilds web/data.js in the repo — that part always happens on schedule.
Automatically (this published page)
Whether this live site shows that fresh data depends on the GitHub Pages workflow also redeploying. The bot commits with the default GITHUB_TOKEN, and GitHub does not let GITHUB_TOKEN pushes trigger other on: push workflows (anti-recursion protection) — so a plain on: push Pages workflow can silently go stale for hours even though the repo data is current. If the "Last bot run" badge is far older than expected, apply the docs/ci/pages.yml drop-in (adds a workflow_run + hourly redeploy trigger), or in the meantime, manually go to Actions → Deploy dashboard to Pages → "Run workflow" to force an immediate refresh.
Manually
python3 cryptobot.py sweep-live
python3 scripts/build_data_js.py
